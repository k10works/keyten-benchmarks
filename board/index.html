Same machine, same data, same queries.

Every number on this page comes from the public harness in keyten-benchmarks: clone it, run one script, and it installs each engine from PyPI, prepares the dataset, and produces this exact result format on your hardware. Lower is better throughout; per-query bars are scaled to the slowest engine on that query.

Engines run through their current PyPI releases with default settings and an equal thread count. Query results are checked for matching statuses and result sizes before timings are compared; a query an engine does not complete is shown as a gap and excluded from the common-subset total.
