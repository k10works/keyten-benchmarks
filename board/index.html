Same machine, same data, same queries.

Every number on this page comes from the public harness in keyten-benchmarks: the runners prepare the data, check query results, and record engine versions, binaries, and measurement settings. Suite notes identify development builds, host conditions, and reused competitor measurements where applicable. Lower is better throughout; per-query bars are scaled to the slowest engine on that query.

Engine versions and measurement protocols are recorded with each result. Current runners validate complete query outputs before timing. A query an engine does not complete is shown as a gap and excluded from the common-subset total. Raw timing differences alone do not establish statistical significance.
